# NetPulse — Live 3D Network Traffic Animator

## Quick Start
1. Install Npcap (Windows) or libpcap (Linux/macOS).
2. Install Python packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the live packet capture backend:
   ```bash
   sudo python server.py
   ```
4. Open `index.html` in your browser to watch live packets animate in 3D.
